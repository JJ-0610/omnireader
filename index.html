크로스 플랫폼 동기화 & 백업

GitHub Pages는 정적 호스팅이므로 자체 DB 서버가 없습니다. 대신 아래 두 가지 방식으로 아이폰·안드로이드·윈도우 간 읽기 진행률, 하이라이트, 메모, 설정을 동기화할 수 있습니다.

1) GitHub Gist 클라우드 동기화 (무료 · 서버 불필요)
GitHub 설정에서 gist 권한이 있는 Personal Access Token을 발급받아 입력하면, 비공개 Gist에 진행률·하이라이트·설정을 자동 저장하고 다른 기기에서 불러옵니다.
2) JSON 파일 수동 백업 / 복원
